Register

So to create a registration form, first I create the basic text field first for the base, the form element. After that I started designing it. First I encapsulate the form inside a big div, the main content. Then I create div for each field so as to separate them from the other. I also used two external font, Poppins and Material Design Icon font to design this website. I use an online generator for the @font-face and copied it. I also added an animation-like design to the Submit button by using the :hover property. I also used flexbox to align the items. I made sure the padding and margin for each element are right by trying each value to see if it fits. I also added an image to fill the blank space. But I think the most important thing to design a website is to structure the website correctly first. By structuring the website, you can focus on each part first rather than the whole at once.
